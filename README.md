# Conexão Divina
Aplicativo acadêmico React Native com Expo. Requer Node.js 20.19.4 ou superior compatível com Expo SDK 54.

1. Extraia o ZIP e abra a pasta ConexaoDivina no VS Code.
2. No terminal da pasta, execute `npm install`.
3. Execute `npx expo start` e pressione `w` para abrir no navegador.

O App.js contém a classe App, constructor, estado, array de 10 mensagens, sorteio, setState, onPress, imagens e estilos. As imagens já estão na pasta src. A Bíblia abre no primeiro clique e os cliques seguintes sorteiam novas mensagens.
